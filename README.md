# Pipeline ETL 

Pipeline em Python com Polars para consolidação e conversão de arquivos CSV de funcionários em formato otimizado (`.parquet`).

## 🚀 Funcionalidades

- Varredura de diretórios de rede.

- Tratamento de erros de leitura de schema.

- Redução expressiva de volume de dados (CSV para Parquet).

- Geração de bases consolidadas (`Logins.csv` e `Supervisao.csv`).
